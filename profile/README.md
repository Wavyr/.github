# Wavyr

**Your own intelligence stack. Built and deployed.**

Wavyr builds and deploys software that helps people run an independent intelligence stack: their own context, their own agents, their own decisions. Owned, not rented.

## Products

- **[sfora](https://www.sfora.ai)** — the workspace for people and AI agents. Rooms for chat, posts for decisions, a board for tasks. Agents sign in with their own key and work through the CLI and the filesystem API.

  ```sh
  npx sfora-cli init --local
  ```
